# Documentación de Instalación

## Instalación de Python

### En Windows

1. **Descargar Python**:
    - Visita [python.org](https://www.python.org/downloads/) y descarga el instalador para Windows.

2. **Instalar Python**:
    - Ejecuta el instalador y asegúrate de marcar la opción "Add Python to PATH".
    - Sigue las instrucciones del instalador.

3. **Verificar la instalación**:
    - Abre el símbolo del sistema (cmd) y ejecuta:
      ```bash
      python --version
      ```
    - Deberías ver la versión de Python instalada.

### En macOS

1. **Descargar Python**:
    - Visita [python.org](https://www.python.org/downloads/) y descarga el instalador para macOS.

2. **Instalar Python**:
    - Ejecuta el instalador y sigue las instrucciones.

3. **Verificar la instalación**:
    - Abre la terminal y ejecuta:
      ```bash
      python3 --version
      ```
    - Deberías ver la versión de Python instalada.

## Instalación de Visual Studio Code

1. **Descargar Visual Studio Code**:
    - Visita [code.visualstudio.com](https://code.visualstudio.com/) y descarga el instalador para tu sistema operativo.

2. **Instalar Visual Studio Code**:
    - Ejecuta el instalador y sigue las instrucciones.

3. **Verificar la instalación**:
    - Abre Visual Studio Code y verifica que se abra sin errores.

## Instalación de Librerías

### Matplotlib

1. **Instalar Matplotlib**:
    - Abre la terminal o el símbolo del sistema y ejecuta:
      ```bash
      pip install matplotlib
      ```

2. **Verificar la instalación**:
    - Ejecuta el siguiente script en Python:
      ```python
      import matplotlib
      print(matplotlib.__version__)
      ```

### NetworkX

1. **Instalar NetworkX**:
    - Abre la terminal o el símbolo del sistema y ejecuta:
      ```bash
      pip install networkx
      ```

2. **Verificar la instalación**:
    - Ejecuta el siguiente script en Python:
      ```python
      import networkx
      print(networkx.__version__)
      ```

Con estos pasos, deberías tener Python, Visual Studio Code y las librerías Matplotlib y NetworkX instaladas y funcionando correctamente.
